# Project Scripts

This directory contains all scripts for the AGI Benchmark project.

## Script Categories

### Data Generation
Scripts for creating and validating coordination task items.

### Task Implementation
Scripts for implementing kaggle-benchmarks tasks.

### Evaluation
Scripts for running multi-model evaluations and computing metrics.

### Analysis
Scripts for generating visualizations and analysis reports.

## Usage

All scripts should be run from the project root directory:
```bash
python scripts/script_name.py
```
